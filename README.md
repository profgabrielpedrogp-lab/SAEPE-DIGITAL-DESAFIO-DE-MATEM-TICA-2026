# SAEPE Digital — Desafio de Matemática

**EREF Iracema M M Veras**  
**Professor Gabriel Pedro**  
**Turma: 3º Ano — 2026**

Aplicação offline em HTML construída a partir das questões de Matemática dos cadernos **SAEPE C1201 — 2021 e 2022** fornecidos pelo professor.

## Conteúdo

- 52 questões oficiais de Matemática: 26 do SAEPE 2021 + 26 do SAEPE 2022.
- Imagens das questões preservadas a partir dos PDFs fornecidos.
- Modo Treinamento.
- Modo Avaliação.
- Desafio Aleatório.
- Filtros por ano e conteúdo.
- Correção automática.
- Resultado por conteúdo.
- Modo Professor para data show.
- Gabarito ocultável.
- Armazenamento local no navegador.
- Exportação dos resultados em JSON.
- Funciona sem servidor e sem internet.

## Como abrir

Basta abrir `index.html` no Chrome, Edge ou Firefox.

## Como publicar no GitHub Pages

1. Crie um repositório, por exemplo `saepe-digital-3ano-2026`.
2. Envie `index.html` e a pasta `assets`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve.
7. O GitHub Pages disponibilizará o endereço público do projeto.

## Observação pedagógica

Os códigos dos itens foram preservados. As habilidades/descritores não foram inventados quando não estavam identificados nos materiais fornecidos; por isso o sistema registra essa informação como “Não identificado no material fornecido”.

## Uso no laboratório

- Cada aluno usa um computador e informa o próprio nome.
- Para diagnóstico: use o Modo Avaliação.
- Para aprendizagem: use o Modo Treinamento.
- Para discussão coletiva: use o Modo Professor no data show.
- Para comparar dificuldades: utilize o relatório por conteúdo e os resultados exportados.
